# ABELVERSION AGRISENSE

## System Architecture

ABELVERSION AGRISENSE is a data-driven smart agriculture advisory system for Rwanda.

### Main Data Sources

- NISR agricultural statistics
- Weather and rainfall data
- Soil data
- Crop requirements
- Geographic/location data
- Historical agricultural data

### Main Advisory Areas

1. Crop Recommendation
2. Irrigation Advisory
3. Soil and Fertilizer Advisory

### General Flow

Data Sources
↓
Data Processing
↓
Database
↓
Analytics / Machine Learning
↓
Agricultural Advisory
↓
Farmer Dashboard
